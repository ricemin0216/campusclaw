# Spec Delta

## Purpose

将教学材料纳入班级知识库，并以服务端强制的班级归属限制材料写入与读取，防止跨班级的数据访问。

## 本次增删记录

### 新增

- 明确材料保存的 UTF-8 正文是可重建派生检索索引的权威来源。
- 增加索引补建不得改变原始文件、材料记录或班级归属的场景。

### 删除

- 无。本次不放宽材料格式、大小限制、角色权限或班级隔离要求。

## ADDED Requirements

### Requirement: 服务端强制执行班级数据边界
系统 SHALL 将每位用户和每份教学材料关联至班级，并在服务端对材料读取、列表查询和材料操作强制执行班级成员关系校验。服务端 SHALL 对认证用户不具备成员关系的班级材料访问请求返回 HTTP 403。

#### Scenario: 成员读取本班材料
- **WHEN** 已认证用户请求属于其所在班级的材料
- **THEN** 服务端仅返回该用户获授权访问的本班材料

#### Scenario: 成员请求其他班级的材料
- **WHEN** 已认证用户请求属于其他班级的材料记录
- **THEN** 服务端返回 HTTP 403，且不返回该班级的材料内容或元数据

#### Scenario: 客户端请求其他班级的材料列表
- **WHEN** 已认证用户请求限定到其他班级的材料列表
- **THEN** 服务端返回 HTTP 403，而不是依赖客户端隐藏控制项

### Requirement: 教师上传材料并写入班级知识库
系统 SHALL 允许已认证教师向其具有成员关系的班级上传教学材料，并创建材料记录及关联到该班级的知识库记录。服务端 SHALL 对教师不具备成员关系的目标班级上传请求返回 HTTP 403。

#### Scenario: 教师向本班上传材料
- **WHEN** 已认证教师向其所在班级上传教学材料
- **THEN** 系统存储材料，并在同一次成功操作中创建关联到该班级的知识库记录

#### Scenario: 教师向其他班级上传材料
- **WHEN** 已认证教师尝试向其他班级上传教学材料
- **THEN** 服务端返回 HTTP 403，且不创建材料或知识库记录

#### Scenario: 学生绕过上传页面
- **WHEN** 已认证学生直接向其所在班级发送上传请求
- **THEN** 服务端返回 HTTP 403，且不创建材料或知识库记录

### Requirement: 班级材料列表
系统 SHALL 提供需认证的班级材料列表，该列表返回请求者所在班级的知识库记录，并 SHALL 包含教师成功上传所创建的记录。

#### Scenario: 上传的材料出现在班级列表中
- **WHEN** 教师成功向某班级上传材料，且该班级的已认证成员请求材料列表
- **THEN** 列表包含对应的知识库记录

#### Scenario: 班级列表排除其他班级的记录
- **WHEN** 已认证成员请求其所在班级的材料列表
- **THEN** 服务端不返回其他班级的任何知识库记录

### Requirement: 受限格式上传与正文留存
系统 SHALL 仅接受扩展名为 `.txt` 或 `.md` 的教学材料，扩展名比较不区分大小写，且单个文件大小 SHALL NOT 超过 10 MB（10 × 1024 × 1024 字节）。系统 SHALL 保存原始上传文件及其 UTF-8 文本正文，并将正文与材料记录关联；该正文 SHALL 作为后续可重建的派生检索索引的权威来源。

#### Scenario: 教师上传允许格式的材料
- **WHEN** 已认证教师向其所在班级上传不超过 10 MB 的 `.txt` 或 `.md` 文件
- **THEN** 系统保存原始文件、UTF-8 正文、材料记录和关联知识库记录

#### Scenario: 拒绝不允许的文件格式
- **WHEN** 教师尝试上传扩展名不是 `.txt` 或 `.md` 的文件
- **THEN** 服务端返回 HTTP 400，且不创建文件、材料记录或知识库记录

#### Scenario: 拒绝超过大小上限的文件
- **WHEN** 教师尝试上传大于 10 MB 的文件
- **THEN** 服务端返回 HTTP 413，且不创建文件、材料记录或知识库记录

#### Scenario: 由已保存正文补建派生索引
- **WHEN** 运维人员对已上传材料执行检索索引补建
- **THEN** 系统使用材料已保存的 UTF-8 正文作为索引来源，原始文件、材料记录和班级归属保持不变

### Requirement: 本班成员再次打开材料正文
系统 SHALL 提供需认证的材料正文查看页。该页面 SHALL 在服务端校验材料所属班级的成员关系后，向本班教师或学生显示已保存的 UTF-8 正文和原文件下载入口；Markdown 正文 SHALL 以文本方式显示而不作为 HTML 执行。

#### Scenario: 本班成员打开已上传材料
- **WHEN** 已认证的本班成员打开已上传材料的查看页
- **THEN** 系统显示该材料保存的正文，并提供受保护的原文件下载入口

#### Scenario: 其他班级成员打开材料
- **WHEN** 已认证用户打开不属于其所在班级的材料查看页
- **THEN** 服务端返回 HTTP 403，且不返回材料正文、文件内容或元数据

### Requirement: 教师删除本班材料
系统 SHALL 仅授权具有目标班级成员关系的教师删除该班材料。成功删除 SHALL 移除材料记录、关联知识库记录及持久化的原始文件；学生或非本班教师的删除请求 SHALL 返回 HTTP 403。

#### Scenario: 本班教师删除材料
- **WHEN** 已认证的本班教师删除本班已上传材料
- **THEN** 系统移除该材料的文件、材料记录和知识库记录，后续查看或下载返回 HTTP 404

#### Scenario: 学生或跨班教师删除材料
- **WHEN** 学生或不属于该材料班级的教师尝试删除材料
- **THEN** 服务端返回 HTTP 403，且材料、知识库记录和文件保持不变
