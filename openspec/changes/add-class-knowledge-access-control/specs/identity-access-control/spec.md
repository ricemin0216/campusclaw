# Spec Delta

## Purpose

定义教师和学生的安全身份验证与服务端授权边界，确保受保护资源仅向已认证且具备相应角色的用户开放。

## 本次增删记录

### 新增

- 将 `OPENAI_API_KEY`、`MYSQL_PASSWORD` 与 `MYSQL_ROOT_PASSWORD` 明确纳入服务端秘密保护范围。
- 增加检索与数据库秘密只能由服务端读取、不得进入页面、API 响应或日志的场景。

### 删除

- 无。本次不移除既有认证、密码哈希或会话授权契约。

## ADDED Requirements

### Requirement: 账号密码认证
系统 SHALL 使用账号标识和密码认证教师与学生账户，并在登录成功后建立已认证会话。

#### Scenario: 教师成功登录
- **WHEN** 教师提交有效的账号凭据
- **THEN** 系统认证该教师，并授予其访问受保护教师资源的权限

#### Scenario: 学生成功登录
- **WHEN** 学生提交有效的账号凭据
- **THEN** 系统认证该学生，并授予其访问受保护学生资源的权限

#### Scenario: 凭据无效
- **WHEN** 用户提交未知账号或错误密码
- **THEN** 系统拒绝认证，且不建立已认证会话或凭据

### Requirement: 受保护资源认证与页面跳转
系统 SHALL 要求受保护页面和受保护 API 完成认证。未认证的受保护页面请求 SHALL 被跳转至登录页，未认证的受保护 API 请求 SHALL 以 HTTP 401 拒绝。

#### Scenario: 未认证访客打开受保护页面
- **WHEN** 未认证访客请求受保护页面
- **THEN** 系统将该访客跳转至登录页

#### Scenario: 未认证调用者调用受保护 API
- **WHEN** 未认证调用者调用受保护 API
- **THEN** 系统拒绝该请求，且不返回受保护数据或执行请求的操作

### Requirement: 服务端角色授权
系统 SHALL 在服务端为每项受保护操作强制执行教师和学生权限。仅教师 SHALL 被授权上传教学材料；即使学生绕过用户界面，其上传请求也 SHALL 以 HTTP 403 拒绝。

#### Scenario: 教师上传教学材料
- **WHEN** 已认证教师为其所在班级调用教学材料上传操作
- **THEN** 服务端在通过班级边界检查后授权该操作

#### Scenario: 学生调用上传 API
- **WHEN** 已认证学生调用教学材料上传 API
- **THEN** 服务端返回 HTTP 403，且不创建材料或知识库记录

### Requirement: 预置班级用户
系统 SHALL 提供可重复执行的初始化数据，包含 A 班、B 班、分配至 A 班的教师账户和学生账户，以及分配至 B 班的学生账户。初始化数据 SHALL 支持验证本班访问和跨班拒绝，而无需手动编辑数据库。

#### Scenario: 创建初始化数据
- **WHEN** 初始化一个全新的应用数据库
- **THEN** A 班、B 班、A 班教师、A 班学生和 B 班学生均可用，并具备指定角色和班级成员关系

#### Scenario: 使用预置账户测试隔离
- **WHEN** A 班教师或学生登录后请求 B 班材料
- **THEN** 服务端基于预置的班级成员关系拒绝该请求

### Requirement: 凭据与密钥保护
系统 SHALL 仅以密码哈希形式存储账户密码，且 SHALL NOT 持久化明文密码（包括预置账户）。认证签名或加密密钥 SHALL 仅通过服务端环境变量提供，且 SHALL NOT 暴露给浏览器客户端、API 响应、受版本控制的配置或日志。应用使用的 OpenAI API 密钥、MySQL 应用账户密码和 MySQL 管理员密码同样 SHALL 仅由服务端 `.env` 或部署环境变量提供，且 SHALL NOT 出现在客户端、响应、日志或版本控制文件中。

#### Scenario: 持久化账户凭据
- **WHEN** 系统创建或更新账户密码
- **THEN** 系统持久化密码哈希，而不是提交的明文密码

#### Scenario: 配置认证密钥
- **WHEN** 启用了认证的应用启动
- **THEN** 应用从服务端环境变量获取认证密钥，且不向客户端返回该值

#### Scenario: 持久化预置账户密码
- **WHEN** 初始化过程创建预置教师或学生账户
- **THEN** 数据库仅存储生成的密码哈希，不存储任何明文密码值

#### Scenario: 配置检索与数据库秘密
- **WHEN** 运维人员为启用检索的部署配置 OpenAI 与 MySQL 凭据
- **THEN** 应用仅从服务端环境读取这些值，且不会在页面、API 响应或日志中返回其值
