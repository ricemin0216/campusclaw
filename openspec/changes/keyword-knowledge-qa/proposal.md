# Proposal

## Why

现有系统只能返回材料切片列表；学生或教师仍需自行判断哪些切片共同回答了问题。增加基于问题关键词的可追溯问答，可在不引入新的生成式聊天模型的前提下，将本班材料中的直接证据组织成简明回答。

## What Changes

- 新增受保护的本班知识问答 API：接收问题，拆分关键词，仅在该班级的 MySQL 全文索引中检索证据。
- 基于命中切片正文生成确定性的摘录式回答，并返回提取出的关键词、引用材料和材料打开链接；回答不编造材料外内容。
- 关键词没有任何有效命中时返回“资料中未找到相关内容”，并返回空的关键词命中与引用列表。
- 在现有 Bearer 认证、角色和服务端班级隔离之上实现；学生与教师均可提问，但跨班调用仍返回 403。
- 在浏览器材料工作区增加提问入口和回答展示，复用受保护 API。

## Capabilities

### New Capabilities

- `keyword-knowledge-qa`: 基于问题关键词、班级材料全文索引和可追溯切片证据的确定性知识问答。

### Modified Capabilities

- 无。

## Impact

- 受影响代码：`app/retrieval.py` 的关键词拆分和证据组装、`app/__init__.py` 的问答 API 与浏览器工作区、检索测试。
- 新增 API：计划提供 `POST /api/classes/<class_id>/questions`，要求 `Authorization: Bearer <JWT>`。
- 不新增外部生成模型、向量库结构或新的秘密；问答仅查询 MySQL 全文索引，因此不调用嵌入服务。
