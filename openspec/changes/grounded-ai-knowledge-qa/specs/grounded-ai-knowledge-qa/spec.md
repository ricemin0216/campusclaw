# Spec Delta

## Purpose

在现有班级材料检索与确定性问答之上提供受控的生成式回答，使师生得到连贯答案，同时始终能查看服务端确认的本班材料证据与原始内容。

## ADDED Requirements

### Requirement: 基于本班材料的 AI 问答

系统 SHALL 提供要求 Bearer Token 的 AI 问答接口，接收目标班级和非空问题。服务端 SHALL 在调用对话模型前验证调用者属于目标班级，并仅将该班级已就绪、可信检索命中的材料切片作为模型上下文。教师和学生均可提问；未认证调用 SHALL 返回 HTTP 401，跨班调用 SHALL 返回 HTTP 403，且两者均不得触发模型调用。

#### Scenario: 本班用户获得基于材料的回答

- **WHEN** 已认证本班成员的问题命中至少一条可信材料切片
- **THEN** 系统返回由对话模型生成、仅依据该班材料上下文的回答和服务端生成的材料引用

#### Scenario: 跨班 AI 问答被拒绝

- **WHEN** 已认证用户向不属于其班级的 AI 问答接口提交问题
- **THEN** 系统返回 HTTP 403，且不向模型发送问题、材料正文或其他班级数据

### Requirement: 证据约束与可追溯引用

系统 SHALL 将模型上下文限制为有限数量和有限长度的服务端检索切片，并以不可信参考资料的形式传递。系统 SHALL 指示模型仅依据给定资料回答，资料不足时明确说明未找到相关内容。API 响应中的 `citations` SHALL 由服务端从实际发送的切片构造，而非采用模型自行生成的链接、材料标题或引用；每项 SHALL 包含材料标题、切片序号、Unicode 字符区间、摘录及受保护材料 URL。

#### Scenario: 模型回答附带服务端引用

- **WHEN** 对话模型成功基于多个材料切片返回回答
- **THEN** 响应中的每个引用对应实际提供给模型的本班切片，且用户可通过受保护 URL 打开该材料

#### Scenario: 材料包含指令性文字

- **WHEN** 命中材料正文中包含要求模型改变角色、忽略规则或泄露数据的文字
- **THEN** 系统仍将其仅作为参考资料处理，并且不因该文字扩大模型上下文或绕过班级隔离

### Requirement: 无证据与模型故障处理

系统 SHALL 在没有可信本班切片时返回 `answer: "资料中未找到相关内容"` 和空 `citations`，并且 SHALL NOT 调用对话模型。对话模型超时、认证失败、限流、非预期响应或其他上游失败时，系统 SHALL 返回受控的 HTTP 502 错误，不得向客户端返回 API 密钥、完整提示词、原始上游响应或不属于调用者班级的材料内容。

#### Scenario: 无关问题不调用模型

- **WHEN** 本班成员的问题没有任何可信材料检索命中
- **THEN** 系统返回固定的无结果回答和空引用列表，且不调用对话模型

#### Scenario: 对话模型不可用

- **WHEN** 已有可信材料证据但对话模型调用失败或超时
- **THEN** 系统返回 HTTP 502 和通用的 AI 问答不可用错误，且不泄露上游敏感信息

### Requirement: 对话模型服务端配置

系统 SHALL 仅通过服务端配置读取 `CHAT_MODEL`，默认使用已批准的 `doubao-seed-2-1-lite-260915`，并通过现有服务端嵌入网关地址与 API 密钥调用 OpenAI 兼容 Chat Completions 接口。模型名称、网关地址和 API 密钥 SHALL NOT 出现在浏览器代码、认证响应或日志中；缺少必需的网关地址或 API 密钥时应用 SHALL 失败启动。

#### Scenario: 使用已配置模型启动

- **WHEN** 部署环境提供有效的网关配置、API 密钥和 `CHAT_MODEL`
- **THEN** 应用启动并仅在有本班证据的 AI 问答请求时调用该模型

### Requirement: 浏览器 AI 问答入口

系统 SHALL 在已认证材料工作区提供独立的 AI 问答入口。浏览器 SHALL 使用内存中的 Bearer Token 调用 AI 问答 API，并以文本渲染模型答案及服务端引用；浏览器 SHALL NOT 接收或存储对话模型 API 密钥。

#### Scenario: 浏览器查看 AI 回答和引用

- **WHEN** 已登录用户在材料工作区提交有证据的问题
- **THEN** 页面显示 AI 回答和可打开的服务器引用材料，不显示模型服务端配置或秘密
